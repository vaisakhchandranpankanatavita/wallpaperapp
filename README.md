# 4K Wallpaper

A minimal, light-theme 4K wallpaper app built with **Expo (SDK 57)**, **Gluestack UI v5**, **Moti** and **React Navigation**.

| Welcome | Home | Detail |
| --- | --- | --- |
| Tilted, drifting collage with a "Start Explore" CTA | Sticky header, category pills, search, 2-column masonry grid, floating glass tab bar | Full-screen photo, glass info panel (views / downloads / category / tags), Save · Apply actions |

## Tech stack

| Concern | Library |
| --- | --- |
| Framework | Expo managed workflow, React Native 0.86, TypeScript |
| UI | Gluestack UI v5 (copy-in components in `components/ui`, styled with NativeWind v5 / Tailwind v4) |
| Animation | Moti (on Reanimated 4) |
| Navigation | React Navigation 7: native stack + bottom tabs |
| Data | TanStack React Query over mock data |
| Images | `expo-image` (plugged into Gluestack's `createImage`) |
| Icons | `lucide-react-native` |
| Extras | `expo-blur`, `expo-linear-gradient`, `expo-haptics`, `expo-media-library`, `expo-file-system` |

## Getting started

```bash
npm install
npx expo start          # press i / a, or scan the QR code with Expo Go / a dev build
```

Useful checks:

```bash
npx tsc --noEmit                       # typecheck
npx expo export --platform android     # make sure the JS bundle builds
```

### How the project was set up (for reference)

```bash
npx create-expo-app@latest wallpaperapp --template blank-typescript
npx expo install react-native-reanimated react-native-worklets react-native-safe-area-context \
  react-native-screens react-native-svg expo-blur expo-linear-gradient expo-image \
  expo-media-library expo-file-system expo-haptics expo-font expo-splash-screen \
  @react-navigation/native @react-navigation/native-stack @react-navigation/bottom-tabs \
  @tanstack/react-query moti lucide-react-native @expo-google-fonts/inter react-dom react-native-web
npx gluestack-ui@latest init --use-npm -y
npx gluestack-ui@latest add box text heading pressable hstack vstack input image icon button avatar center --use-npm -y
```

> `gluestack-ui init` adds `nativewind/babel` to `babel.config.js`. With NativeWind v5 that preset isn't needed (Metro handles `className`), and on web it creates a circular import inside react-native-web, so this project leaves it out.

## Animation notes

- **`ScalePressable`** wraps every interactive element: it pops in from `{ scale: 0.9, opacity: 0 }` on mount and shrinks slightly while pressed, using a Moti spring.
- **Grid cards** fade in and slide up 24px, staggered by index (the stagger is capped so long lists don't lag).
- **Detail screen** opens as a full-screen modal that slides up from the bottom. The photo settles from `scale 1.08` to 1 while the glass panels fade in one after another. Tap the photo to hide the controls and preview the wallpaper alone.
- **Tab bar**: a white thumb springs to the active tab.

## Platform notes

- **Set as wallpaper**: neither iOS nor Expo has an API for setting the system wallpaper, so **Apply** saves the image to Photos and tells the user how to set it. On Android, true one-tap apply needs a custom native module (`WallpaperManager`).
- **Glass blur**: iOS uses a real `BlurView`. Android and web use a translucent tint, because Android's native blur needs a `BlurTargetView`.
- **Images**: if an Unsplash URL fails to load, the app falls back to a deterministic `picsum.photos` image.
